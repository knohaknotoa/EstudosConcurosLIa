# Changelog

## Site V2 — reorganização estrutural

- Conteúdo dos Ranks 1–5 separado em páginas próprias.
- `index.html` convertido em painel de estudos.
- Navegação interna fixa por Rank.
- Modos Estudar, Revisão rápida, Questões, Flashcards, Simulado e Tudo.
- Busca global por seções e assuntos.
- “Continuar estudando” com último ponto visitado.
- Marcação manual de seções estudadas.
- Caderno de erros e marcação “Revisar depois”.
- Flashcards com classificação Fácil/Médio/Difícil e filtro de difíceis.
- CSS e JavaScript extraídos para arquivos compartilhados.
- Compatibilidade mantida com GitHub Pages e com o armazenamento local anterior.
